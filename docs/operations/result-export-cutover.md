# Result export cutover

Issue #142 moves browser-session result export creation, status, and download to
Go ownership for these routes:

| Public path | Go path | Response |
| --- | --- | --- |
| `POST /api/admin/result-exports` | `/admin/result-exports` | Creates a tenant-scoped completed export descriptor with HTTP `202` |
| `GET /api/admin/result-exports/{resultExport}` | `/admin/result-exports/{resultExport}` | Returns the tenant-owned export descriptor |
| `GET /api/admin/result-exports/{resultExport}/download` | `/admin/result-exports/{resultExport}/download` | Downloads a completed, non-expired export payload |

## Compatibility decision

Laravel creates a queued `result_exports` row and dispatches a Laravel queue job.
The Go worker process is still a fail-closed skeleton, so Go generates the
export payload inline during `POST /admin/result-exports`, persists the row as
`completed`, and still returns the Laravel-compatible descriptor with HTTP
`202 Accepted`. This avoids dual queue consumption and keeps status and download
semantics available immediately after creation.

The descriptor keeps the Laravel fields: `id`, `format`, `status`, `filename`,
`contentType`, `url`, `expiresAt`, `authorized`, `ready`, and `errorMessage`.
JSON exports use `application/json`; Markdown exports use `text/markdown`.

## Tenant isolation

Every export operation scopes by the active Go browser-session tenant:

- creation first loads the performed test cycle by `id` and `idCostumer`;
- payload generation reads performed tests and steps by the same tenant and run;
- status and download load `result_exports.id` with `idCostumer`;
- foreign runs and exports return the same missing-resource response as absent
  resources.

Export payloads include only run, test, and step summary fields. They do not
include stored `postmanData`, step `data`, screenshots, headers, cookies,
session identifiers, API keys, tokens, passwords, or secrets.

## Deployment and rollback

Before route cutover, run the MySQL-backed export integration test and smoke
`POST`, `GET`, completed download, queued `409`, expired `410`, and foreign
`404` behavior in staging.

Rollback is route-level: switch the three result-export routes back to Laravel.
Rows generated by Go use the existing `result_exports` table and remain readable
by Laravel. Because Go does not enqueue Laravel jobs, there are no Laravel queue
messages to drain for this slice.
